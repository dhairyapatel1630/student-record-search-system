## Overview of Student Records Search System

The Student Records Search System is a Python-based application designed to store, display, and search student records using their roll numbers. It provides a simple menu-driven interface that allows users to manage student information efficiently.

The system stores each student's roll number, name, and marks using Python lists and dictionaries. It offers two searching techniques: Linear Search and Binary Search, allowing users to find student records using either method. It also checks for duplicate roll numbers and displays the student's result as PASS or FAIL based on a minimum passing mark of 35.

The main objective of this project is to demonstrate how Python programming concepts and searching algorithms can be used to manage student information accurately and efficiently.
